# Starfall Client

A lightweight Fabric client utility mod for Minecraft Java 1.21.11.

Features: custom ClickGUI, nearby container/spawner finder toggles, on-screen finder results, configurable scan radius, simple persistent settings.

## Build
Open the **Actions** tab and run the workflow, or push a commit. Download the `StarfallClient` artifact from the completed workflow.

Client-only. Fabric Loader + Fabric API required.
